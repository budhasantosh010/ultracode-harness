---
name: tasks
description: View and manage workflow tasks
---

Manage tasks:

1. Use `get_pending_tasks` to see pending tasks
2. Use `get_task_events` to see task lifecycle
3. Use `complete_task` to mark tasks done
4. Use `task_stop` to cancel stuck tasks
5. Use `task_update` to change task properties
6. Show the user a summary of all tasks and their statuses
