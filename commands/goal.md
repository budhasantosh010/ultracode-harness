---
name: goal
description: Set, view, or clear a persistent session goal that guides all subsequent work
---

Manage session goals:

1. `/goal set "description"` — Set a session goal. This goal will be persisted in context and referenced in all future responses.
2. `/goal` — Show the current session goal
3. `/goal clear` — Clear the current session goal

When a goal is set, keep it visible in your reasoning. Reference it when making decisions about what to do next. If a user's request doesn't align with the goal, clarify before proceeding.
