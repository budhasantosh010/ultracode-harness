Manage OpenCode configuration:

1. To view config: Read the opencode.jsonc file at ~/.config/opencode/opencode.jsonc
2. To view a specific section: Use read_config tool or grep the config file for the key
3. To modify: The user must edit the file manually (config is loaded at startup only)
4. Show the relevant config section to the user and explain what each field does
