---

Manage MCP servers:

1. List MCP servers: `opencode mcp list`
2. Check MCP server status and available tools
3. If a specific server needs attention, read the opencode.jsonc mcp configuration section
4. MCP servers are configured in the `mcp` field of opencode.jsonc with type (local/remote), command, and env vars
